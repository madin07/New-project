# 🧮 Math Magician

Math Magician is a responsive web project designed to provide a simple and user-friendly mathematical experience.

The project includes three main pages:

- Home
- Calculator
- Quote

## 👥 Teamwork

This project was developed collaboratively by a team. The work was divided between team members, with each member responsible for specific pages and tasks.

One part of the team focused on developing the Calculator page, including its structure, design, responsiveness, and functionality.

The other part focused on developing the Home and Quote pages and their design and layout.

The team then combined the different sections into one complete website and worked together to maintain a consistent design and user experience.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub

## 📚 What We Learned

Through this project, we practiced:

- Creating a multi-page website
- Using HTML, CSS, and JavaScript together
- Building an interactive calculator
- Creating responsive web pages
- Using Git and GitHub
- Working collaboratively as a team
- Managing and combining different parts of a project

## 🚀 Future Improvements

Future improvements could include adding more mathematical functions, improving the user interface, adding more interactive features, and further improving the responsive design.
